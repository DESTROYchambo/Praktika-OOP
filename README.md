# Обробка колекцій

## Постановка задачі
Вам потрібно виконати наступне:
1. Реалізувати можливість скасування (undo) операцій (команд).

2. Продемонструвати поняття "макрокоманда"
   
3. При розробці програми використовувати шаблон Singletone.

4. Забезпечити діалоговий інтерфейс із користувачем.

5. Розробити клас для тестування функціональності програми.

   
## Опис
Використовуючи код попередніх робіт, розширити програму з можливістю скасування операції, використання шаблну Singleton, а також використовувати діалоговий інтерфейс з користувачем.
