# Паралельне виконання. Шаблон Worker Thread

## Постановка задачі
Вам потрібно виконати наступне:
1. Продемонструвати можливість паралельної обробки елементів колекції (пошук мінімуму, максимуму, обчислення середнього значення, відбір за критерієм, статистична обробка тощо).
2. Управління чергою завдань (команд) реалізувати за допомогою шаблону Worker Thread.
   
## Опис
Реалізувати можливість паралельної обробки елементів колекції(пошук мінімуму, максимуму, обчислення середнього значення), також потрібно використовувати шаблон проектування Worker Thread для управління чергою завдань.

## Структура проекту
```
├── src/                            
│   ├── AvgCommand.java             # Обчислення середнього значення
│   ├── CommandQueue.java           # Управління чергою команд і виконання у окремих потоках
│   ├── ExecuteConsoleCommand.java  # Реалізація виконання команд у окремих потоках
│   ├── Main.java                   # Головний клас 
│   ├── MaxCommand.java             # Обчислення максимального значення
│   ├── MinMaxCommand.java          # Реалізація обчислення мінімального та максимального значення
|   └── Queue.java 
├── README.md                       # Документація
└── img/                            # Папка з скріншотами       
```
