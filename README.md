# Графічний інтерфейс

## Постановка задачі
Вам потрібно виконати наступне:
Розробити графічний інтерфейс та реалізувати його.
   
## Опис
Необхідно реалізувати графічний додаток мовою Java, який обчислює кінетичну енергію тіла за заданою масою та швидкістю, а також знаходить двійкове представлення цілої частини цієї енергії. Додаток включає в себе, табличне відображення результатів обчислення та кнопки, кожна з яких виконує окрему дію.
## Структура проекту
```
├── src/                            
│   ├── EnergyFrame.java              # Клас графічного інтерфейсу
│   ├── EnergyResult.java             # Клас для зберігання результатів обчислень
│   ├── FileHandler.java              # Клас роботи з файлами
│   ├── Main.java                     # Головний клас 
│   └── KineticEnergyCalculator.java  # Клас обчислення кінетичної енергії та двійкового уявлення
├── README.md                       # Документація
└── img/                            # Папка з скріншотами       
```
